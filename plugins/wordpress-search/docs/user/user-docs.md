# User docs

This guide explains how content authors use the `bcew-search` blocks to build search experiences in WordPress.

## Before you begin

- The `bcew-search` plugin is installed and activated in WordPress.

## Search blocks

Insert the blocks from the Block Inserter under the `SEARCH` category. Each block provides reusable search controls for building flexible, accessible experiences. Browse the block reference in the sidebar for features, settings, and usage of each block.
