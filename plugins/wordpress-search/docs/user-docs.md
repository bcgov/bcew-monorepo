# User docs

This guide explains how content authors use the `bcew-search` blocks to build search experiences in WordPress.

## Before you begin

- The `bcew-search` plugin is installed and activated in WordPress.

## Search blocks

Insert the blocks from the Block Inserter under the `SEARCH` category. Each block page covers its features, settings, and usage:

- [Search Bar](./Blocks/Search/): Search posts and documents.
- [Search Active Filters](./Blocks/SearchActiveFilters/): Show and clear active filters.
- [Search Modal](./Blocks/SearchModal/): Present search in a modal overlay.
- [Search Post Filter](./Blocks/SearchPostFilter/): Filter by post type and metadata.
- [Search Result Count](./Blocks/SearchResultCount/): Display the total number of results.
- [Search Results Post Metadata Display](./Blocks/SearchResultsPostMetadataDisplay/): Show metadata with results.
- [Search Results Sort](./Blocks/SearchResultsSort/): Reorder results by field and direction.
- [Search Taxonomy Filter](./Blocks/SearchTaxonomyFilter/): Filter results by taxonomy.

![`Finding Search Blocks in the Block Inserter`:](./images/SEARCH_BLOCKS.gif)

The blocks provide reusable search controls for building flexible, accessible experiences.
