# Add a CHEFS form block to a page or post

1. Open the page or post in the block editor.
2. Insert the CHEFS Form block.
3. In the block sidebar, enter the CHEFS Form ID or share URL. The block saves the normalized Form ID and displays a read-only preview.
4. Optionally enter a confirmation message to show after a successful submission.
5. Publish or update the page.
