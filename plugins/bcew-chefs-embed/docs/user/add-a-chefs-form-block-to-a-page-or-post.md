# Add a CHEFS form block to a page or post

1. Open the page or post in the block editor.
2. Insert the CHEFS Form block.
3. In the block sidebar, enter the CHEFS Form ID or paste the form's share URL.
4. Optionally enter a plain-text confirmation message.
5. Publish or update the page.

The form must be published, use the **Public** login option, and list the
WordPress site's origin in its CHEFS **Allowed origins**. See [Before you
begin](./before-you-begin) for details.
