# Before you begin

Before configuring a form in WordPress, you will need:

- access to the CHEFS service
- a Form ID from your form
- a published version of the form in CHEFS; draft-only forms cannot be embedded
- a CHEFS form using the **Public** login option
- the WordPress site's origin added to the form's **Allowed origins** in CHEFS

The block embeds Public forms anonymously. Private forms and forms that do
not allow the WordPress site's origin cannot be loaded by this integration.
