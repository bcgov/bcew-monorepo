# User docs

This guide explains how site administrators can add and manage existing CHEFS forms for use in WordPress pages and posts.

The CHEFS Forms settings page has been removed. Adding a form by Form ID or URL will move to the CHEFS Form block settings in the block editor. Forms that were already saved continue to work. The plugin documentation is linked from the **Documentation** link on the plugin's row in **Plugins**.
