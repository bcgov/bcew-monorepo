# BC Extended Web Plugin

The BC Extended Web Plugin provides reusable WordPress features for site navigation, accessibility, and content presentation.

## Key features

- **Notification Banner:** Display a configurable message at the top of each page.
- **Content Security Policy:** Configure which sources the site can load for scripts, styles, images, fonts, media, connections, and frames.
- **Skip Navigation:** Give keyboard users a link and supporting script to jump to the main content.
- **In-Page Navigation:** Provide numbered jump links to sections on long pages.
- **Auto Anchor:** Generate stable heading IDs and anchors for deep links and tables of contents.
- **Navigation and Breadcrumb blocks:** Provide standardized site navigation and breadcrumb trails.
