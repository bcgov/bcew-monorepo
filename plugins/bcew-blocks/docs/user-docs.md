# User docs

This guide explains how content authors insert and configure blocks provided by `bcew-blocks`.

## Before you begin

- The `bcew-blocks` plugin is installed and activated in WordPress.

## Add a block

1. In the editor, insert blocks using the block inserter and search for the block name.
2. Configure block settings in the sidebar.
3. Publish or update the page.

## Icon

Displays a single icon with configurable size and accessibility labeling.

- Category: Media
- Intended use: visual icon element in content layouts

### Icon settings

- **Pick an icon**: selects the icon to display.
- **Icon size**: display size (Small, Medium, Large, or XLarge). Default is Medium.
- **Decorative**: whether assistive technology should ignore the icon. Off by default.
- **Accessible name**: accessible text label when the icon is not decorative.

### Accessibility

- When **Decorative** is on, the icon does not require an accessible name.
- When **Decorative** is off, provide a meaningful **Accessible name**.

## Media & Text Layout

Presents media and text side-by-side with configurable image placement.

- Category: Media
- Intended use: paired media and narrative content sections

### Media & Text Layout settings

- Image: select an image from the media library.
- **Image on right**: places the image to the right of the text. By default, the image is on the left.

### Authoring guidance

- Keep text concise when media is the primary focus.
- Use image placement to support reading flow and hierarchy.
