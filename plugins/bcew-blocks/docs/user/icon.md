# Icon

Displays a single icon with configurable size and accessibility labeling.

- Category: Media
- Intended use: visual icon element in content layouts

## Icon settings

- **Pick an icon**: selects the icon to display.
- **Icon size**: display size (Small, Medium, Large, or XLarge). Default is Medium.
- **Decorative**: whether assistive technology should ignore the icon. Off by default.
- **Accessible name**: accessible text label when the icon is not decorative.

## Accessibility

- When **Decorative** is on, the icon does not require an accessible name.
- When **Decorative** is off, provide a meaningful **Accessible name**.
