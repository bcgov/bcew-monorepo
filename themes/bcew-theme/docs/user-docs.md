# User docs

Site author guidance for activating the BC Extended Web Theme and using its existing Site Editor patterns.

## Theme overview

The BC Extended Web Theme is built for BC Government websites hosted on the Digital Engagement Solutions (GDX) platform. It implements the BC Government Design System to provide consistent branding and user experience.

The theme provides:

- Pre-built patterns for building pages from ready-made components.
- BC Government design tokens and styling.
- Responsive patterns that adapt to mobile devices.
- Accessible patterns designed to support WCAG compliance.

The theme is exclusively for BC Government WordPress sites hosted by GDX / Digital Engagement Solutions.

## Activate the theme

1. Access your WordPress site's dashboard.
2. Go to Appearance → Themes.
3. Find **BC Extended Web Theme**.
4. Click **Activate**.

## Use patterns

1. Create or edit a page or post.
2. Click the **+** button to add a block.
3. Open the **Patterns** tab.
4. Browse available patterns under categories such as Banners, Cards, Text layouts, Contact sections, and Team displays.
5. Click a pattern to add it to the page.

See the [Patterns Overview](./guide/SiteEditor/Patterns/PatternsOverview) and [How to Add a Pattern](./guide/SiteEditor/Patterns/HowToUsePatterns) for more guidance.
