# Design System WordPress Child Theme: FIRB

FIRB is a BCEW child theme built on `bcew-theme`.

Development and testing use the monorepo tooling. See the [FIRB developer documentation](docs/index.md) for build, wp-env, and visual regression commands.

The project is maintained in the [BCEW monorepo](https://github.com/bcgov/bcew-monorepo/tree/main/themes/design-system-wordpress-child-theme-firb).
